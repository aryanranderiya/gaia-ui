# Footer

A dark landing-page footer with link columns, a canvas-drawn halftone wordmark that ripples under the pointer, and a three-column bottom bar for a status slot, brand mark, and social links.

<ComponentPreview name="footer/default" />

## Usage in Gaia

The footer of the GAIA landing page. The halftone wordmark renders the logo and lettering as a dot grid that swells around the cursor and ripples on click.

## Installation

```package-install
npx shadcn@latest add "https://ui.heygaia.io/r/footer"
```

## Usage

```tsx
import { Footer } from "@/components/ui/footer";

export default function Example() {
  return (
    <Footer
      sections={[
        {
          title: "Product",
          links: [
            { label: "Download", href: "/download" },
            { label: "Pricing", href: "/pricing" },
          ],
        },
      ]}
      wordmark={{ text: "GAIA", logoSrc: "/logo.webp" }}
    />
  );
}
```

## Examples

### With social links and bottom bar slots

```tsx
<Footer
  sections={sections}
  socialLinks={[
    {
      label: "GitHub",
      href: "https://github.com/acme",
      external: true,
      icon: <GithubIcon aria-hidden="true" />,
    },
  ]}
  startSlot={<StatusBadge />}
  brandSlot={<CompanyLogo />}
/>
```

### Custom glow or wallpaper background

```tsx
// CSS glow (default), tinted to your brand color
<Footer sections={sections} glowColor="#7c3aed" />

// Or a wallpaper image
<Footer sections={sections} backgroundSrc="/images/footer-glow.webp" />
```

### Standalone wordmark

```tsx
import { FooterWordmark } from "@/components/ui/footer-wordmark";

<FooterWordmark text="ACME" logoSrc="/logo.webp" />
```

## Props

### Footer

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sections` | `FooterSection[]` | - | Link columns rendered across the top |
| `socialLinks` | `FooterSocialLink[]` | - | Icon links in the bottom-right corner |
| `wordmark` | `{ text: string; logoSrc?: string }` | - | Halftone wordmark config; omit to hide |
| `startSlot` | `ReactNode` | - | Bottom-left slot (status badge, copyright) |
| `brandSlot` | `ReactNode` | - | Centered bottom slot (company mark) |
| `backgroundSrc` | `string` | - | Wallpaper image behind the footer |
| `glowColor` | `string` | `"#00bbff"` | Accent of the fallback CSS glow |
| `className` | `string` | - | Additional CSS classes |

### FooterWordmark

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | - | Word rendered as the halftone dot grid |
| `logoSrc` | `string` | - | Image mark composed left of the text |
| `aspectRatio` | `string` | `"23 / 4"` | Reserved ratio before the first draw |
| `fontClassName` | `string` | `"font-serif font-bold"` | Classes on the font probe |
| `className` | `string` | - | Additional CSS classes |

## Notes

- The footer is designed dark: the glow, white link text, and blend modes assume a dark page beneath.
- The wordmark is decorative (`aria-hidden`) and stays static when `prefers-reduced-motion` is set.
- Link columns render inside a `nav` element labeled "Footer" for screen readers.
